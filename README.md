# VIBES — landing page

Page statique (HTML, CSS, JS sans dépendance, police Inter via Google Fonts).
Tokens issus de `vibes_design_system_v1.md`.

## Lancer en local

```
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000.

## Maquettes à ajouter

Les écrans ne sont pas recréés : la page utilise tes PNG du Drive, tels quels.
Copier depuis le dossier Drive `vibes_10_ecrans_image_choisie` vers `assets/screens/` :

| Fichier | Section |
| --- | --- |
| `01_accueil.png` | Hero |
| `02_explorer_activites.png` | Expérience, explorer |
| `03_detail_activite.png` | Expérience, explorer |
| `07_mon_mood.png` | Expérience, moment pour soi |
| `09_tips_vibes.png` | Expérience, habitudes |
| `05_mon_crew.png` | Crew |

Tant qu'un fichier manque, un cadre en pointillés indique son nom.

## Éléments non fournis (non inventés)

- Logo officiel : le mot « VIBES » est écrit en texte (Inter Bold, bleu VIBES).
- Photographies d'étudiants : aucune n'est utilisée.
- Contact, réseaux sociaux, pages légales, lien de téléchargement ou d'inscription : aucun.
- Image de partage social (`og:image`) : à ajouter quand elle existe.
